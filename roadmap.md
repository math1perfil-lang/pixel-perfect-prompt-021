# RULIS — Roadmap

Cidade inicial: Florianópolis (dados demonstrativos identificados).

## Fase 1 — Fundação
- [ ] Identidade visual e design system
- [ ] Navegação (barra inferior mobile, lateral desktop)
- [ ] Autenticação (e-mail/senha, Google, Lovable) + redefinição de senha
- [ ] Banco de dados com RLS
- [ ] Onboarding em 7 etapas + perfil de lazer
- [ ] Termos de uso e privacidade (LGPD)

## Fase 2 — Experiência central
- [ ] Home personalizada (próximo tempo livre, seções)
- [ ] Meu Tempo Livre (disponibilidade + compromissos + intervalos)
- [ ] Calendário (dia/semana/mês)
- [ ] Explorar (mapa + lista + filtros)
- [ ] Detalhe da atividade + deslocamento estimado
- [ ] Motor de recomendação por regras, pesos configuráveis, explicações
- [ ] Painel administrativo (lugares, eventos, usuários, métricas)

## Fase 3 — Diferenciação
- [ ] RULIS Agora
- [ ] RULIS Surpresa
- [ ] Meu Fim de Semana (roteiros)
- [ ] Orçamento de lazer
- [ ] Saia do Óbvio
- [ ] Memória de experiências (Meus rolês + retrospectiva)

## Fase 4 — Social
- [ ] Amigos, convites, grupos, disponibilidade compartilhada, votação

## Fase 5 — Inteligência e expansão
- [ ] Clima (Open-Meteo, sem chave)
